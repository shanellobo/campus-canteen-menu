

## Menu Management

The staff can manage the campus canteen menu.

- Add new food items with prices and stock quantities.
- Edit existing food item details.
- Delete food items from the menu.
- Enable or disable food items.
- Validate food names, prices and stock quantities.
- Display success or error messages to the user.

The menu is saved in the browser using localStorage.
